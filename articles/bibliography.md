# Complete Bibliography and References

The full reference list for the diagnostics implemented in this package
is maintained as the help topic
[`?algorithms_bibliography`](https://diogoribeiro7.github.io/heteroTests/reference/algorithms_bibliography.md),
which collects the primary source for every test. The package citation
is below.

``` r

citation("heteroTests")
```
