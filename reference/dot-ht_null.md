# Ecosystem integration helpers

These utilities extend the package to work smoothly with broader R
ecosystem tools such as tidymodels workflows, parsnip model objects,
`survey` designs, data.table-backed pipelines and broom tidiers. They
are exported only where user interaction is expected; internal helpers
remain undocumented.

## Usage

``` r
.ht_null
```

## Format

An object of class `NULL` of length 0.
