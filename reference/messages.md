# Standardized error and warning messages

Provides a central location for common error and warning strings used
across the package. The package signals problems through internal
versions of
[`std_error()`](https://diogoribeiro7.github.io/heteroTests/reference/std_error.md)
and
[`std_warning()`](https://diogoribeiro7.github.io/heteroTests/reference/std_warning.md);
the exported names are deprecated since 0.14.0.
