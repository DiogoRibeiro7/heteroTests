# Motivation letter

Dear Editors,

Please consider the manuscript **"heteroTests: A Unified and Reproducible Framework for Heteroscedasticity Diagnostics in R"** for publication in *The R Journal*.

The article presents the CRAN package `heteroTests`, which provides a common software layer for heteroscedasticity diagnostics that are otherwise distributed across several R packages and interfaces. The manuscript focuses on the software contribution: a consistent diagnostic API, standard `htest` return objects, batch execution, reproducible metadata, streaming implementations for large data sets, validation against established implementations, and an integrated diagnostic-to-remediation workflow.

The empirical results in the article are designed to be reproducible from the accompanying R code. Reference comparisons, simulation studies, and computational benchmarks are regenerated from the package version analysed in the manuscript rather than copied from static results.

The package is available on CRAN and its source code, tests, documentation, and manuscript materials are publicly maintained.
