# Contributing to heteroTests

We welcome contributions in the form of pull requests or issue reports.

## Workflow

1. Fork the repository and create feature branches from `main`.
2. Restore development dependencies by running `./setup.sh` and then execute `R CMD check --no-manual`.
3. After changing a help page, `NEWS.md` or `ROADMAP.md`, regenerate the
   documentation site's pages with `Rscript tools/build-docs.R`, and after
   changing a vignette, its guide page with `Rscript tools/render-guides.R`.
   Commit what they write; `mkdocs build --strict` builds the site (see
   `docs/development.md`).
4. Add unit tests for any new functionality and update relevant docs.

To run style checks, unit tests and coverage in one step, first run
`./setup.sh` to install the development packages (including
`quickcheck`) and then execute:

```bash
Rscript scripts/run_checks.R
```

Run `lintr::lint_package()` to ensure the code matches the `.lintr` style
configuration before submitting.

Code should follow the tidyverse style guide and respect CRAN policies
(no unchecked warnings or notes from `R CMD check`).

All R source lives directly in `R/`, one file per diagnostic, named after the
function it defines (for example `R/performBPTest.R`). There are no
subdirectories.

### Documentation and roxygen2

`man/` is **mixed**: roxygen2 writes 86 of the 138 help pages from the roxygen
blocks in `R/`, and the other 52 are written by hand.

- **A page that starts with `% Generated by roxygen2: do not edit by hand`.**
  Change its block in `R/`, not the `.Rd` file. Then run `devtools::document()`
  with the roxygen2 of `RoxygenNote` in `DESCRIPTION`, and commit the pages it
  writes with your change. The "Quality checks" workflow runs roxygen2 at that
  version and fails if `man/` or `NAMESPACE` then differ from your commit. A
  page edited by hand, or a block changed without running `document()`, fails
  CI.
- **A page without that line.** roxygen2 does not overwrite it, and prints
  `Skipping <file>: it already exists and was not generated by roxygen2`.
  Nothing regenerates these 52 pages. When you change a function signature, or
  anything else that one of them documents, update its `.Rd` file in the same
  commit. 45 of them belong to a roxygen block in `R/` that roxygen2 skips, so
  users never read that block, and the CI check does not see these pages.
- **`NAMESPACE`** is written by hand too: an `@export` tag exports nothing until
  `NAMESPACE` has the line.

Moving the 52 pages and `NAMESPACE` to roxygen2 is the 0.18.0 item "52 help
pages and `NAMESPACE` are written by hand" of `ROADMAP.md`.

`tests/testthat/test-documentation-consistency.R` runs `tools::codoc()`,
`tools::checkDocFiles()` and `tools::undoc()`, so the local test suite catches
a mismatch between a page and its function before CI does.

If ``R CMD check`` fails with ``command not found`` you need to
install R and ensure the ``R`` executable is available. Consult your
package manager or visit <https://cran.r-project.org> for
installation instructions.

Continuous integration runs `R CMD check` automatically for every
pull request via GitHub Actions, so make sure the checks pass locally
before submitting.

Please open an issue to discuss substantial changes or cross-language
API additions. Pull requests should include a concise description in the
body and reference any related issues.
